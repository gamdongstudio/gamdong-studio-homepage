# 감동사진관 홈페이지

경기도 광명 감동사진관 홈페이지입니다. 가족사진, 증명·여권사진, 프로필사진을 소개합니다.

## 페이지 구성
| 파일 | 내용 |
|---|---|
| index.html | 메인 |
| family.html | 가족사진 |
| id-photo.html | 증명·여권사진 |
| profile.html | 프로필사진 |
| gallery.html | 갤러리 |
| price.html | 가격안내 |
| contact.html | 예약·오시는 길 |

## 자주 고치는 곳
- **전화번호·주소·영업시간·카카오톡·네이버 예약 주소**: `js/site.js` 맨 위
- **가격**: 각 페이지 파일의 가격 부분
- **사진**: `images` 폴더에 넣고, `gallery.html` 안내 문구대로 추가
- **색상**: `css/style.css` 맨 위
